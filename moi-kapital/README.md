# Мой Капитал

Личный учёт финансов: инвестиционный портфель с котировками Мосбиржи, бюджет, цели и 15 калькуляторов.

- Сайт: статические файлы (`index.html`, `styles.css`, `js/`), без сборки. Работает на GitHub Pages.
- Данные: Supabase-проект `moi-kapital` (stursnvoaqdlcfaoaitg). Вход по ссылке из письма. Каждая таблица защищена RLS: пользователь видит только свои строки.
- Котировки: Edge Function `moex-sync` забирает акции, фонды и рублёвые облигации с ISS Мосбиржи в таблицу `securities`. Запускается pg_cron каждые 30 минут в торговые часы (пн–пт) и раз в сутки в 22:00 UTC; в приложении есть кнопка «Обновить котировки».
- Демо без входа: добавьте `?demo` к адресу.
- Телефон: откройте сайт в Safari/Chrome → «Поделиться» → «На экран Домой».

## Структура
- `js/app.js` — экраны, работа с базой, быстрый ввод, импорт/экспорт
- `js/calcs.js` — калькуляторы
- `js/util.js` — форматирование и графики
- `js/mock.js` — демо-режим
- `sw.js`, `manifest.webmanifest` — установка на телефон и работа без сети
