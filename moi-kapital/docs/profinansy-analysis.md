# Разбор profinansy.ru (октябрь 2026)

Изучено изнутри аккаунта: портфели, бюджет, цели, рынок, страница бумаги, калькуляторы. Карта сайта — 268 страниц.

## Разделы
- **Цели**: цели (активные / достигнутые), желания с подборками, чек-листы с шаблонами и папками. Поиск, фильтр, сортировка, плитка/список, PDF-отчёт.
- **Бюджет** (`/wallet`): счета по типам (дебетовые и кредитки, накопительные, инвестиции, кредиты, займы), история по дням с иконками категорий, фильтры «расходы / доходы / переводы / накопления», аналитика (динамика баланса, расходы и доходы по категориям, сравнение периодов, календарь трат по дням, тренды), планы с календарём следования. Ввод трат голосом или текстом через Telegram-бота. Режим «только расходы» без остатков.
- **Портфели**: несколько портфелей (обычные, объединённые, синхронизированные с брокером, турнирные, демо) каруселью с мини-графиком. Шапка: капитал в выбранной валюте, общая прибыль + за день, пассивный доход % и ₽ за год. Вкладки: Состав / Операции / Обзор / Аналитика ИИ (premium).
  - Состав: по классам (акции, облигации, фонды, деньги) или «по частям портфеля»; у каждой таблицы — доля класса, настройка колонок, фильтр, «показать все», раскрываемые строки, логотипы компаний, статус «Активные / Проданные».
  - Колонки акций: доля, кол-во, ср. цена, текущая, изменение %, див. доходность, общая прибыль ₽ и %, вложено, дивиденды, прибыль по сделкам, стоимость.
  - Колонки облигаций: + сумма купонов, купон, дата погашения, ближайший купон, уровень листинга, дюрация, амортизация, дата оферты.
  - Деньги: валюты с курсом.
  - Обзор: внесено / выведено, дивиденды и купоны, число сделок, суммы покупок и продаж, комиссии, налог; график «вложено vs стоимость» за период; средняя доходность против индекса Мосбиржи; распределение по классам, валютам, странам, секторам, бумагам.
- **Инвестиции**: обзор рынков (часы работы бирж, индексы, валюта, металлы, тепловая карта, лидеры роста и падения), скринер (premium), подборки, пассивный доход (premium), сравнение активов, индикатор трендов, календари (дивиденды, купоны, оферты, IPO, отчёты, экономические — premium), экономические циклы, брокеры, новости.
- **Страница бумаги**: шапка с логотипом и ценой, «В портфель», «В пасс. доход», вердикты фунд./тех. анализа, голосование «вырастет / упадёт», вкладки (обзор, ИИ-анализ, обсуждение, отчётность, дивиденды, прогнозы, новости), график с отметками своих сделок и дивидендов, консенсус-прогноз аналитиков, прогноз ближайших дивидендов, мультипликаторы против отрасли и рынка, плюсы и минусы от ИИ.
- **Калькуляторы**: 14 штук; слева список, по центру результат (плитки + столбчатая диаграмма + таблица по годам), справа форма с ползунками, PDF-отчёт.

## Визуальный стиль
Светло-серый фон, белые карточки со скруглением ~16px, чёрная шапка, фиолетовый акцент, тёмные карточки счетов и портфелей. Левая колонка-подменю внутри каждого раздела. Много рекламных баннеров и всплывающих окон с вебинарами.

## Что мешает (из отзывов и личного осмотра)
- Всплывающая реклама вебинаров почти на каждой странице, баннеры внутри калькуляторов.
- Ключевые функции за подпиской: календари, скринер, пассивный доход, ИИ-аналитика.
- Таблицы портфеля перегружены: у облигаций 20 колонок.
- Бюджет и портфель живут отдельно, общей картины капитала нет.
